# 구나경 RPA 포트폴리오 ✨

안녕하세요!  
저는 반복되는 업무를 자동화하고 효율화하는 데 관심이 많은 대학생 구나경입니다.  
RPA(UiPath), Python, ERP, 데이터 시각화 등에 흥미를 가지고 있으며,  
대학생 때 배운 내용과 실습 프로젝트들을 정리하여 기록하고 있습니다.

본 저장소는 제가 진행한 RPA 프로젝트들을 모아 정리한 포트폴리오 공간입니다.

## 🛠 기술 스택

- **RPA 툴**: UiPath (웹 자동화, 엑셀 자동 입력, 파일 처리 등)
- **데이터 처리**: Excel, PDF, 웹 스크래핑
- **관심 분야**: 반복업무 자동화, ERP 실무, 실시간 정보 수집 및 보고서 생성
